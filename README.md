# AdvancedGunpowder

> Musket combat and weapon proficiency for TF-Minecraft.

AdvancedGunpowder adds a deliberate firing-and-reloading cycle to custom firearms. Ammunition, weapon handling, character attributes, and practice with an individual weapon all influence combat, giving gunpowder weapons their own rhythm within TF-Minecraft's RPG systems.

> **Archived repository:** this README describes the preserved plugin implementation.

## Features

- **Timed weapon handling** — equipping and reloading take time, with separate appearances for loading and loaded weapons.
- **Ammunition management** — firearms require their matching ammunition and track the shots available before another reload.
- **Weapon proficiency** — using a weapon can improve a player's familiarity with that particular item, up to ten proficiency levels.
- **Attribute-based handling** — character attributes influence reload speed and shot spread, while weapon proficiency further improves accuracy.
- **Custom combat behaviour** — weapon damage, range, spread, and piercing contribute to how a shot resolves against its target.
- **Audiovisual feedback** — firing sounds, visible shot traces, item models, and reload progress make the weapon's state visible during play.

The plugin connects custom MMOItems weapons with MMOCore character progression and MythicLib combat. Its focus is the moment-to-moment experience of carrying, loading, and firing a gunpowder weapon.
